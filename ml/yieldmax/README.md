# Urbora YieldMax ML · Team run guide

Open [Urbora_YieldMax_ML.ipynb](Urbora_YieldMax_ML.ipynb) to train and test the actual estimators. The notebook is self-contained and starts with empty outputs. It reads Urbora's pinned historical SQLite data, verifies the two checksums, constructs lag features, fits both estimators, backtests them, then calls the fitted model for your inputs.

## Run with teammates

- **Google Colab.** Open [Colab](https://colab.research.google.com/), upload the notebook, choose a CPU runtime, and select **Run all**. [Colab FAQ](https://research.google.com/colaboratory/faq.html)
- **Kaggle.** Import the notebook, use a CPU notebook, allow internet for the public input download and first dependency installation, then select **Run All**. With internet disabled, attach the two pinned SQLite files from [the repository snapshot](https://github.com/Shafin2954/urbora/tree/68dfdcd731ddcd4f451ea801ea629056c377536d/data). Point the setup cell's `DATA_DIRECTORY` at their folder and have `scikit-learn==1.9.1` installed in the runtime. [Kaggle Notebooks documentation](https://www.kaggle.com/docs/notebooks)

The automatic download uses `agristats.db` and `agribase_clean.db` at the pinned commit. Neither the notebook nor its model training requires a GPU, API key or cloud server setup. The package cell requires Python 3.11 or later. The tested local environment is recorded in [metrics.json](metrics.json). If you load the exported fitted model instead of retraining, use matching library versions and load only a trusted model file.

## Try a prediction

In **Run a fresh inference**, keep `Rangpur`, `lentil_masur`, horizon `2` and two bigha for the first run. For a second test, set `METHOD = "hist_gradient_boosting"` or switch to a supported district listed beneath the output. The prediction cell builds its inputs from the historical data and calls `predict()` on the fitted estimator. Changing area scales the harvest estimate and leaves the district-level yield rate alone. The output shows the data cutoff, crop year, estimate, historical error band, and last observation's row ID.

With the pinned snapshot, a two-year horizon predicts the crop year ending 2027. The output is a district-level planning estimate. The training file lineage is recorded in the metrics. Individual rows still await reconciliation against the original yearbook pages.

## Verified results

| Estimator | One-year MAE (176 rows) | Two-year MAE (88 rows) |
| --- | ---: | ---: |
| Last observation | **49.35** | **82.51** |
| Urbora Holt | 79.35 | 123.71 |
| Shrunk ridge | 51.79 | 93.10 |
| Histogram gradient boosting | 67.11 | 99.48 |

MAE is in kg/ha. The notebook selects the best **ML** candidate on earlier validation seasons. It separately reports the two benchmark methods. Last observation performed best on the held-out seasons. This benchmark reuses the historical split from the first Urbora experiment, so use newer seasons for a fresh model-promotion decision.
