# Fonts

All free, all SIL Open Font License, all on Google Fonts. The site loads them from Google
Fonts with `display=swap`; Noto Sans Bengali (on most Android phones) is the fallback.

| Role | Family | Link |
|---|---|---|
| Display (headlines, Bangla wordmark) | Tiro Bangla | https://fonts.google.com/specimen/Tiro+Bangla |
| Text (body, UI) | Hind Siliguri 400/500/600 | https://fonts.google.com/specimen/Hind+Siliguri |
| Mono (judge-facing trace) | JetBrains Mono | https://fonts.google.com/specimen/JetBrains+Mono |

For the video, the deck and Canva, install the TTF files from those pages, or pick the same
families in Canva (all three are in Canva's library).
